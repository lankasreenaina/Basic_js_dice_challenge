# 🎲 Dicee Game

A simple web-based dice game built using **HTML, CSS, and JavaScript**.

When the page is refreshed, two dice are rolled randomly. The player with the higher number wins, and the result is displayed at the top of the page.

## 🚀 Features

* Generates random dice values for both players.
* Updates dice images dynamically using JavaScript.
* Displays the winner automatically.
* Shows a draw message when both players roll the same number.
* Simple and responsive UI.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation)

## 🎮 How It Works

1. A random number between 1 and 6 is generated for Player 1.
2. A random number between 1 and 6 is generated for Player 2.
3. The corresponding dice images are displayed.
4. The page compares both values and announces:

   * Player 1 Wins 🚩
   * Player 2 Wins 🚩
   * Draw 🚩
